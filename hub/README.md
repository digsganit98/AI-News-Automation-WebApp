# R&D Hub inbox

Add one article here as a pull request: an `.html` or `.pdf` file, up to 5 MB.
Put these lines in the pull request description:

```
Title: How we cut RAG latency 40%
Team: Platform Team
Author: Priya N.
Tags: RAG, latency
Summary: One or two sentences on what the article shows.
Domain: GenAI
Cloud: AWS
Vertical: BFSI
```

Checks run on the pull request and say what to fix. When a reviewer merges it, the article is
cleaned, moved to the site and listed in the R&D Hub. Nothing in this folder is published as is.
